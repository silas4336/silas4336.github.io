Console Dashboard

置於 Windows 桌面最底層的遊戲儀表板：其他視窗照常使用，切回桌面時看到的是遊戲牆、時鐘與硬體狀態。以 Tauri 2（Rust）與 React 開發，自動掃描 Steam、Epic、GOG 與 Xbox 已安裝的遊戲並補上直式封面。

做法與取捨

取捨集中在常駐程式的成本：全螢幕遊戲或最大化視窗蓋住儀表板後，即暫停所有繪製與更新；使用者在其他程式中時，各項資料的更新間隔放慢為三倍，切回時立即補抓。
