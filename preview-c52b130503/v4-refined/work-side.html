01

Find Your Buddy

有線上版 ↗

10 題問答推薦適合的同伴動物，共 14 種結果。支援中英日三語，作答完成後生成可分享至社群的圖卡。

投入最多的並非題目設計，而是配對百分比的校準：初版結果多集中在 60% 附近，缺乏鑑別度；調整權重後，典型結果落在具說服力的區間。

02

模擬面試挑戰

有線上版 ↗

為青年活動製作的單頁互動網站，包含 8 道面試情境與作答回饋。免費、免登入、約三分鐘完成，這三項資訊置於按鈕下方，因報名轉換的主要流失點在此。

03

FakeGPS

GitHub ↗

以 Mac 設定 iPhone 的 GPS 位置，用於測試依賴定位的 App。原生 SwiftUI + MapKit，支援 Apple Maps 搜尋、點選地圖設定與常用地點書籤。

除了設定單一座標，另支援沿真實道路以步行、單車或開車的速度移動：導航與健身類 App 要驗證的是移動過程，停在一個定點測不出來。

取捨主要放在安裝與日常使用的阻力上。權限改為安裝時設定一次，之後每次啟動不再要求密碼；安裝腳本一併處理相依套件與權限，使用者不需要安裝 Xcode。開發機本身未裝完整 Xcode，因此以命令列 swiftc 編譯並自行組裝 app bundle。原始碼以 MIT 授權公開，含安裝腳本與跨平台網頁版。

04

Console Dashboard

下載 ↗

置於 Windows 桌面最底層的遊戲儀表板：其他視窗照常使用，切回桌面時看到的是遊戲牆、時鐘與硬體狀態。以 Tauri 2（Rust）與 React 開發，自動掃描 Steam、Epic、GOG 與 Xbox 已安裝的遊戲並補上直式封面。

取捨集中在常駐程式的成本：全螢幕遊戲或最大化視窗蓋住儀表板後，即暫停所有繪製與更新；使用者在其他程式中時，各項資料的更新間隔放慢為三倍，切回時立即補抓。

另支援手把操作、以熱鍵疊出的速覽畫面、中英雙語、首次啟動引導，以及經簽章驗證的自動更新。實驗性的外掛小工具在沙盒中執行，發布前以一個刻意設計的惡意外掛測試；修正測試中找到的兩個漏洞後，51 項攻擊全數攔下。原始碼為私有，安裝檔透過公開的 release repo 發布。

05

Watch Later Cleaner

GitHub ↗

YouTube 的「稍後觀看」累積數千部影片後，官方介面只能逐部手動移除。這個 Chrome 擴充功能可依加入順序、觀看狀態、影片長度、發布時間與關鍵字篩選，預覽確認後批次刪除。

刪除不模擬點選選單，而是透過 YouTube 頁面本身的指令一次送出一整批，並讀取回應確認成功；失敗時拉長間隔重試。由於刪除無法復原，預設為模擬模式、刪除前另行確認，並可先匯出 CSV 備份。擴充功能不讀取 cookie，也不將資料傳送至其他地方。實測約 3,000 部的清單，刪除 800 部約需 32 秒。原始碼以 MIT 授權公開。

06

供貨監控

Python

監控數個購物網站的商品供貨狀態。要判斷的不是怎麼抓資料，而是什麼時候該通知：僅於「缺貨轉為有貨」的狀態轉換時發送單次通知，狀態保存於本機，避免同一件事重複提醒導致訊息被忽略。

三個站點各自採用不同的擷取方式，其中一站具反爬蟲偵測，擷取方式另行處理。
