Side projects

Things I built on my own time

All four are mine end to end.

Find Your Buddy

live ↗

A 10-question quiz that matches you with one of 14 companion animals. Three languages, and it generates a card you can post to a story.

The part that took longest was not the questions — it was calibrating the match percentage. The first version put almost everyone around 60%, which reads as a shrug. After reweighting, a typical result lands where it feels like it is actually about you.

Interview Challenge

live ↗

A one-page interactive site for a youth event: eight real interview scenarios with feedback at the end. Free, no sign-in, about three minutes — all three written under the button, because that is where sign-ups were being lost.

FakeGPS

GitHub ↗

Set your iPhone's GPS location from a Mac. A native SwiftUI + MapKit app with Apple Maps search, tap-to-set, saved places, and a universal binary.

This machine only has the Command Line Tools, no full Xcode — so the app is compiled with swiftc from the terminal, with the .app bundle assembled and signed by hand. The source is public under MIT, with install scripts and a cross-platform web build.

Stock Watcher

Python

Watches a few product pages and tells me when something is back in stock. Three sites need three different approaches; one of them detects scrapers, so it takes a more roundabout route.

More thought went into when to notify than into fetching: it fires once, on the transition from out-of-stock to in-stock, with state kept locally. Otherwise nobody reads the alerts.
